# All `vending=*` values in OpenStreetMap

Source: [taginfo](https://taginfo.openstreetmap.org/keys/vending#values), worldwide, data as of 2026-10-13. Combined values like `drinks;sweets` are split and counted once per part. Counts cover all objects with a `vending` tag (almost all are `amenity=vending_machine`, about 372k worldwide).

**Bold** = documented on the [OSM wiki](https://wiki.openstreetmap.org/wiki/Key:vending). Unmarked = in common use but not documented; often a synonym of a documented value (e.g. `snack` → `snacks`, `beverages` → `drinks`).
